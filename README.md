# Employee Management System (EMS)

A React-based Employee Management System built using React.js, Vite, and Tailwind CSS.

## Features
- Admin Dashboard
- Employee Dashboard
- Employee Management
- Task Creation and Assignment
- Task Status Tracking
- Accept, Complete and Failed Tasks
- LocalStorage for Data Persistence

## Tech Stack
- React.js
- JavaScript
- Tailwind CSS
- Vite
- LocalStorage

## Getting Started

```bash
npm install
npm run dev
```
